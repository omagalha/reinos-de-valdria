# Assets de Reinos de Valdria

Esta pasta separa material bruto, arquivos prontos para o jogo e categorias de produção.

- \`raw/concepts\`: referências visuais que não devem ser carregadas pelo jogo.
- \`sprites\`: personagens, Guardiões, monstros e NPCs exportados para uso direto.
- \`tilesets\`: tiles de 32 × 32 pixels por bioma.
- \`animations\`: efeitos e animações independentes.
- \`audio\`: música e efeitos sonoros.
- \`ui\`: botões, molduras, ícones e cursores.

Antes de adicionar qualquer arquivo, registre-o em \`manifest.json\` e em \`ASSET_LICENSES.md\`.
A prancha em \`raw/concepts\` orienta o estilo, mas não é uma spritesheet pronta para produção.
